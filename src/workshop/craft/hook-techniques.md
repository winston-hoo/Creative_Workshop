# 悬念钩子十法

## 章末钩子的三条铁律

一、钩子必须落在最后一段的最后一句。位置往前挪，读者读完就没劲了。
二、不写作者旁白。「欲知后事如何」一出现，钩子就废了，它把读者的紧张感换成了作者的邀功。
三、相邻两章不许用同一种钩子。连着两章都用突然揭示收尾，读者第二次就猜到套路，第三次就翻页走人。

## 轮换顺序

长篇按下表轮换，一章换一种，十种用完再来一轮：突然揭示、紧急危机、未完成的动作、身份反转、两难选择、神秘物品线索、时间限制、承诺威胁、离奇消失、言外之意。卷末用重的那种，过渡章用轻的那种。

## 突然揭示

1. 定义：在最后一句抖出一个此前没露面的信息，让读者重新理解整章。
2. 用在：反转章、真相章收尾，前面已经埋过至少一处伏笔。
3. 例：「她摘下口罩，我认出了那张遗照上的脸。」
4. 误用：伏笔没埋就硬抖，读者只会觉得突兀，不会觉得震撼。一章最多抖一次。

## 紧急危机

1. 定义：把主角推进一个必须立刻反应的险境，晚一步就出事。
2. 用在：动作章、战斗章收尾，下一章要写主角的反应动作。
3. 例：「刀锋已经贴上了他的喉咙。」
4. 误用：危机必须真能伤到主角。喊了十次狼、每次都被救，读者就不信了。

## 未完成的动作

1. 定义：把一个动作停在半途，不写结果。
2. 用在：日常章、过渡章收尾，下一章从动作的结果接上。
3. 例：「他推开了那扇门——」
4. 误用：不能连着几章都用同一个动作，开门、抬手用完就没张力了。

## 身份反转

1. 定义：抖出某个角色的真实身份，改变他此前所有行为的含义。
2. 用在：人物真相章、卷末章收尾。
3. 例：「救他的人，正是三年前被他亲手送走的人。」
4. 误用：反转前这个人的言行必须对得上新身份，否则是作者硬掰。

## 两难选择

1. 定义：把主角推到两个都不能接受的选项前，让他必须选一个。
2. 用在：情感章、抉择章收尾，下一章写他挑哪边、付什么代价。
3. 例：「救她，还是守住这座城？」
4. 误用：两个选项得都真的肉疼。一边是烂选项、一边是好事，那就不是两难。

## 神秘物品线索

1. 定义：给出一件来历不明的东西，暗示它牵出更大的事。
2. 用在：探查章、过渡章收尾。
3. 例：「盒底压着一枚刻了他名字的铜牌。」
4. 误用：线索必须在本卷内有下文，抛了不收就成了断线，读者会记账。

## 时间限制

1. 定义：给主角的行动加一个明确期限，让倒计时开始走。
2. 用在：任务章、备战章收尾。
3. 例：「三天后子时，城门就关了。」
4. 误用：期限不许无限顺延。说三天就三天，改期一次可以，改两次读者就不数了。

## 承诺威胁

1. 定义：让某个角色明确说出「我要做什么」，把威胁摆到台面上。
2. 用在：敌对关系章、摊牌章收尾。
3. 例：「下个月，我会来收你欠的账。」
4. 误用：说得出就做得到。放了狠话却一直没动作，这个角色就空了。

## 离奇消失

1. 定义：让一个关键的人或物在没有任何预兆的情况下不见。
2. 用在：悬疑章、转折章收尾，下一章从「找」开始。
3. 例：「等我回头，担架上已经空了。」
4. 误用：消失必须留下可查的痕迹，全无痕迹就成了作者偷懒。何况消失不能变成常用的转场手段。

## 言外之意

1. 定义：让角色说一句表面平淡、实际另有所指的话，把意思藏起来。
2. 用在：感情线章、权谋章收尾，下一章揭他的真实意图。
3. 例：「恭喜你，这次真的赢干净了。」
4. 误用：不能藏到读者看不懂。话里的暗指至少要让一半读者当场咂摸出来。

钩子不是断章取义。本章的核心事件该收的收完，钩子只把下一个问题递出去。
