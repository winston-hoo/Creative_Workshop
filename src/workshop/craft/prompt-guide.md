# 提示词完善指南

## 一、模糊词替换表

| 模糊说法 | 可执行写法 |
| --- | --- |
| 写得更爽 | 主角被打压后 3 段内完成反打，旁观者补一句评价 |
| 人物更立体 | 本场新人物给一个具体小动作加一个自利动机 |
| 节奏太慢 | 删掉本章前两段环境描写，从动作切入 |
| 对话太多 | 把第 4 到第 7 段压成一段叙述加一句关键台词 |
| 气氛紧张 | 每段末尾留一个未解决的问题，直到倒数第二段 |
| 感情线推进 | 两人本章有一次距离小于一臂的接触 |
| 反派更可恶 | 反派做一件伤及无辜的具体事，主角亲眼看见 |
| 信息量太大 | 单章最多放两条新设定，每条隔一段再给 |
| 世界观更清楚 | 让一个设定靠角色的使用动作露面，不解释 |
| 结尾更悬念 | 最后一句抛出一个主角答不出的具体问题 |
| 文笔好一点 | 删掉所有「非常」「十分」「无比」，换成具体量 |

右边一列必须能数出来：3 段、2 条、1 句、1 次。数不出来的写法，就还是模糊词。

## 二、一条好指令的五项

1. **谁**：本章视角角色，一个。写名字，不写「主角」。
2. **要什么**：他这一章想拿到什么。落到一件具体东西或一句具体的话。
3. **谁拦着**：挡他的人、规矩，或他自己的毛病。至少写一个。
4. **结束状态**：写「从 A 变成 B」。手里、关系里、认知里各变一样。
5. **章末钩子**：最后一段抛什么。写成一句能直接抄进正文的话。

缺「谁拦着」，模型会让主角一路顺到底；缺「结束状态」，模型会在原地转圈；缺「章末钩子」，模型会自己收尾成完结感。

对照：「写一章主角去拍卖会」是零项；「周砚要在拍卖会上拍下残卷，账房先生抬价阻挠，他散尽积蓄拿到残卷却欠下人债，末尾债主递来一张写着日期的字条」是五项齐全。

## 三、禁令怎么写

- 写具体字面，不写程度。写「不许出现『破折号』『综上所述』」，比「少用书面语」有效。
- 一条禁令只管一件事。禁令越短，检查越快。
- 禁令必须可搜。写完能用查找功能数出次数，才算合格。
- 例句：「本章不出现内心独白式的反问句。」「本章不出现『破折号』。」「本章不出现超过三行的连续环境描写。」

写禁令时不要用「尽量」「适当」「少一点」。这三个词模型无法执行，等于没写。

## 四、自检

把指令念一遍。如果换到任何一章都能套用，它就等于没写，重来。

判据：指令里至少有一个只属于本章的名词——一个人名、一个地名、一件东西。一个都没有，就是泛话。
